## 📖 Sobre o projeto

Este repositório reúne os materiais e códigos-fonte desenvolvidos para a disciplina de **Compiladores**, referente ao semestre letivo 2026.2, da Universidade do Estado do Rio Grande do Norte (UERN).

O projeto tem como objetivo o desenvolvimento de um **transpilador**, utilizando Ruby como linguagem de origem, além da exploração prática dos recursos dessa linguagem por meio de exemplos de código.

Os exemplos foram elaborados para demonstrar diferentes conceitos da linguagem, priorizando a organização, a legibilidade, os comentários explicativos e a aplicação prática dos recursos estudados.

## 🧩 Exemplos de código

A pasta `exemplos-origem/` reúne exemplos relacionados a diferentes recursos da linguagem Ruby, incluindo:

- Tipos de dados e tipagem dinâmica;
- Variáveis, escopo e referências;
- Expressões e operadores;
- Métodos e parâmetros;
- Estruturas de controle e repetição;
- Programação orientada a objetos;
- Concorrência, programação assíncrona e Ractors;
- Tratamento de exceções;
- Eventos e callbacks.

Os exemplos são organizados em arquivos independentes, com nomes descritivos e comentários que auxiliam na compreensão dos conceitos apresentados.
